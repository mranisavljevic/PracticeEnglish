# Unit lists (draft)

Source: `eia-contents.pdf` (Student Book contents pages, *English in Action* 3rd edition, levels 1-4).
The audio file names carry only a track number, so the **track ranges are blank for you to fill in** from the physical books.
Use ranges like `1-8` or lists like `9, 10, 12`; leave blank if a unit has no audio.

Assumptions to confirm:
- The Workbook uses the same unit numbering as its Student Book (the PDF only lists Student Book contents). If a workbook is organised differently, say so.
- Level 1 and 2 have a Welcome Unit (unit 0); Level 3 and 4 start at unit 1.
- "Page" is the Student Book page where the unit starts, which should help you find the matching track numbers in the book.
